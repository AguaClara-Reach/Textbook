# English–Spanish Technical Translation Guide

## Purpose

This guide records the English–Spanish terminology conventions used in the
AguaClara PF70 operation and maintenance manuals. It is intended as a reusable
translation reference for AguaClara technical and educational material,
including the textbook.

Use the preferred terms consistently. Choose a different translation only when
the technical context requires a different meaning, and document that choice
in the project glossary.

## General conventions

- Translate the technical meaning, not merely the individual words.
- Use standard water-treatment terminology where an established term exists.
- Use **flow rate** for `caudal` when the quantity or measurement is emphasized.
  The shorter **flow** is acceptable when the meaning is unambiguous.
- Use **dose** for an amount of chemical per volume of water and **dosing** for
  the process or system. Use **dosage** only when required by a quoted source or
  established external name.
- Use **turbidity**, not *turbidness*. In English, report turbidity in **NTU**;
  in Spanish, use **UTN** unless a governing publication requires otherwise.
- Use **raw water**, **clarified water**, **filtered water**, and **treated
  water** for the corresponding water-treatment stages. Do not use *clean
  water* as a technical synonym.
- Use **sludge** for concentrated settled solids and **floc/flocs** for the
  aggregates formed by coagulation and flocculation.
- In English, use attributive compounds such as **raw-water turbidity** and
  **coagulant dose** when they modify another noun.
- Define abbreviations and AguaClara-specific names at first mention. Retain the
  same abbreviation after it is defined.
- Preserve product names, model numbers, software names, chemical formulas, and
  SI unit symbols. Translate the surrounding description.
- Prefer active, direct instructions in both languages: **Open the valve** /
  **Abra la válvula**.
- Use sentence case for headings unless a publication's style requires another
  convention.

## Terms requiring contextual translation

Some words have more than one correct translation. Determine the physical or
mathematical meaning before translating them.

| Source term | Possible translations | Distinction |
| --- | --- | --- |
| `carga` | **head**, **load**, **charge** | Use **head** for hydraulic energy per unit weight, **load** for an applied quantity or demand, and **charge** for an electrical or batch-loading context. |
| `escala` | **scale**, **graduated scale** | A marked measurement scale. Do not confuse it with `balanza`, a weighing device. |
| `flujo` | **flow**, **flux** | Use **flow** for fluid movement or volumetric rate; reserve **flux** for flow per unit area or another formally defined flux. |
| `resistencia` | **resistance**, **resistor** | **Resistance** is a property; **resistor** is a component. |
| `tratamiento` | **treatment**, **processing** | Use **treatment** for water and wastewater processes. |
| **scale** | `escala`, `balanza`, `sarro` | Translate according to whether it means graduations, a weighing device, or mineral deposits. |
| **settling** | `sedimentación`, `asentamiento` | Use `sedimentación` for particle removal from water; `asentamiento` normally describes structural or soil movement. |

## Maintaining this guide

When a new technical term is introduced:

1. Check authoritative bilingual standards, regulations, and established
   AguaClara usage.
2. Confirm the term in context rather than translating it in isolation.
3. Add one preferred pair to the appropriate table.
4. Add a usage note if a competing translation could change the technical
   meaning.
5. Update the source documents so the preferred term is used consistently.
